# Battery Monitor App

Private cross-platform Flutter companion app for the Battery Monitor firmware.
It connects directly to the monitor over Bluetooth Low Energy; the first
release has no account, cloud service or internet requirement.

## Current milestone

1. Scan only for the Battery Monitor service.
2. Connect to one monitor.
3. Subscribe to Binary Telemetry v1.
4. Show live voltage, current, power, temperature, net Ah and net Wh.
5. Show connection and telemetry-freshness state.

The firmware/app compatibility contract is
[docs/BLE_PROTOCOL.md](docs/BLE_PROTOCOL.md). Treat a protocol change as a
firmware-and-app release decision, not an implementation detail.

Platform permission and signing guidance is in
[docs/PLATFORM_SETUP.md](docs/PLATFORM_SETUP.md).

## Local setup

Flutter is intentionally not bundled in this repository. Install the current
stable Flutter SDK, generate the Android/iOS platform shells, then fetch
dependencies:

```powershell
flutter create --platforms=android,ios .
flutter pub get
flutter test
flutter run
```

Review the files generated by `flutter create` before committing them. Do this
before adding Android or iOS signing settings. Keep signing keys, provisioning
profiles and local properties out of Git.

Use physical devices for BLE testing. The scanner intentionally filters on the
custom Battery Monitor service UUID, not only the advertised device name.

## Project layout

```text
lib/
  ble/       BLE identifiers and connection/subscription boundary
  models/    Versioned, testable binary packet decoder
  screens/   App-level UI and lifecycle state
test/        Packet decoder tests
docs/        BLE compatibility contract and app roadmap
```
